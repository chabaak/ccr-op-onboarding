## Scope And Method

This report inventories Korean-bearing string values from the one live authored pack, `data/scenario/멈춘회전문/*.json`, plus `data/scenario/default-prompts.json`, and Korean-bearing string/template literals from `src/client/shell/*.ts` and `src/client/components/*.ts`. The pack is discovered from `data/scenario/index.json` by selecting the tutorial pack, matching the runtime default. The script deliberately does not import `src/` modules; it parses files as text/JSON, counts Korean characters with Unicode Hangul script matching, and reports `unknown` only for genuinely orphaned records.

The sample is a single pack. The parent plan's three-pack variance premise is stale: `멈춘회전문` is the only live pack in `data/scenario/`, so measured values below are one-pack values and schema ranges are taken from `data/scenario/_schema/` where the schema declares them.

The taxonomy has three buckets: `rendered` means the string reaches a player-visible surface; `model-facing by design` means it is consumed by prompt, runtime, or authoring paths where no screen is intended; `genuinely orphaned` means no current rendered or model-facing path was found.
